# salvador-server

Base MERN backend for the Salvador lab activity.

## Setup

```bash
npm install
copy .env.example .env
npm run dev
```

## Routes

- `GET /api/health`
- `GET /api/users`
- `POST /api/users`
- `GET /api/users/:id`
- `PUT /api/users/:id`
- `DELETE /api/users/:id`
- `POST /api/users/signup`
- `POST /api/users/login`
